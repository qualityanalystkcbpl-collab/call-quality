Setup Guide

How to add your links

  1. Share the Google Sheet / Drive file as "Anyone with the link — Viewer".
  2. Copy the file's ID from the link (the part between the two / slashes).
  3. Open this HTML file in a text editor and find the JOURNEY_CONFIG section near the bottom.
  4. Go to the matching Tab and Stage number, paste the ID into sheetId and driveId, then save the file.
catv: [
  { title: "Induction Training",
    timeline: "Within same business day",
    purpose: "...",
    accountability: "Debjit Roy",
    sheetId: "PASTE_GOOGLE_SHEET_ID",
    driveId: "PASTE_GOOGLE_DRIVE_FILE_ID" },
  ...
]
